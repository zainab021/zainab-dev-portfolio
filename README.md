## ⚙️ Run Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` (bundled with Node.js)

### Step-by-Step Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/zainab021/zainab-dev-portfolio.git
   ```

2. **Navigate into the project directory**:
   ```bash
   cd zainab-dev-portfolio
   ```

3. **Install project dependencies**:
   ```bash
   npm install
   ```

4. **Start the local development server**:
   ```bash
   npm run dev
   ```

5. Open your browser at:
   ```
   http://localhost:3000
   ```

### Production Build

To generate the optimized production bundle:
```bash
npm run build
```
The production-ready files will be generated in the `dist/` directory, ready to deploy instantly to **Vercel**, **Netlify**, or **GitHub Pages**.
